# Frontend - Job Application Portal

Simple, responsive React + Vite application for the Job Application Portal.

## Scripts
```bash
npm install
npm run dev     # Starts Vite dev server (http://localhost:3000)
npm run build   # Builds production bundle
```

## Structure
- `src/components/` - Navbar and JobCard components
- `src/pages/` - Login, Register, Jobs, JobDetails, CandidateDashboard, RecruiterDashboard, AddJob, Applicants
- `src/App.css` - Custom clean CSS styling
